# Personal Site — CLAUDE.md

## Vision

A personal portfolio site styled as a **JRPG character information screen** — the kind you'd find in games like Final Fantasy, Persona, or Chrono Trigger. The UI should feel like opening a party member's status menu: pixel-inspired typography, stat bars, menu panels, and the general aesthetic of a classic RPG HUD.

---

## Sections

### Character Header
- Name, title/role (e.g. "Full Stack Developer"), level or years of experience
- A portrait or avatar area
- A short "bio" line styled as a character description

### Stats
Numeric or bar-based stats representing **programming languages and technical tools**. Think INT, STR, DEX but mapped to real skills:
- Each stat has a name (e.g. "TypeScript", "Python", "SQL"), a value/level, and a bar fill
- Stats should feel like they belong in an RPG stat block

### Skills
A **skill tree or skill list panel** covering **broader competencies** beyond individual languages:
- Examples: System Design, Frontend Architecture, API Design, DevOps, Testing
- Skills can have tiers, descriptions, or unlock conditions written in RPG flavor text
- Could display as a list with icons, or a branching skill tree

### Quests
A **quest log** representing **projects**:
- Each project is a quest with a title, status (Completed, In Progress, Abandoned), and a short description written in quest-log voice ("Sought to build...", "Tasked with...", etc.)
- Could include quest rewards (technologies used, outcomes)
- Active projects shown as "Active Quests", completed ones as "Completed Quests"

---

## Aesthetic Guidelines

- JRPG menu UI: dark backgrounds, bordered panels, pixel or pixel-adjacent fonts
- Color palette should evoke classic RPGs — deep blues, golds, magentas, or a custom theme
- Stat bars with fill animations
- Subtle scanline or CRT texture optional
- Sound effects or click interactions optional but on-brand
- Responsive but primarily designed for desktop (where the full stat screen shines)
